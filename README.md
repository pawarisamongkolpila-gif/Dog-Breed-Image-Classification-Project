Dog Breed Image Classification (สมาชิกจำนวน 4 คน)

โปรเจกต์นี้สอนให้โมเดล Deep Learning ดูรูปสุนัขแล้วบอกว่าเป็นสายพันธุ์อะไรจาก 119 สายพันธุ์ โดยลองเทียบกัน 3 โมเดล(MobileNetV2, InceptionV3, EfficientNetB3) ว่าโมเดลไหนทำนายแม่นยำที่สุด

วัตถุประสงค์
- เพื่อพัฒนาและเปรียบเทียบประสิทธิภาพของแบบจำลอง Deep Learning โดยศึกษาเปรียบเทียบระหว่าง MobileNetV2, InceptionV3 และ EfficienNetB3
- เพื่อหาแบบจำลองที่เหมาะสมที่สุดที่ให้ค่าความแม่นยำสูงในขณะที่ยังใช้ทรัพยากรและเวลาประมวลผลต่ำ

เครื่องมือ: Python · TensorFlow / Keras · Google Colab

ผลลัพธ์: InceptionV3 ได้ Validation Accuracy 88.53% และ Test Accuracy 88.15%

ข้อมูลที่ใช้
- ชุดข้อมูล: Stanford Dogs Dataset จาก Kaggle (120 สายพันธุ์ 20,580 ภาพ)
- ข้อมูลที่ใช้จริง: 119 สายพันธุ์ สายพันธุ์ละ 100 ภาพ รวม 11,900 ภาพ
- การแบ่งข้อมูล: Training 70% | Validation 20% | Test 10% = 8,330 / 2,380 / 1,190 ภาพ (สายพันธุ์ละ 70 / 20 / 10 ภาพ)

ทั้ง 3 โมเดลใช้ Transfer Learning คือนำโมเดลที่เคยเรียนดูภาพจำนวนมากจาก ImageNet มาเป็นพื้นฐาน โดยไม่ปรับส่วนที่เรียนมาแล้ว แล้วฝึกเฉพาะชั้นที่ต่อเพิ่มให้จำแนก 119 สายพันธุ์ใช้ Adam, categorical cross-entropy และ batch size 32 เหมือนกัน

ข้อสังเกตและข้อจำกัด
- แต่ละโมเดลใช้การตั้งค่าที่แตกต่างกัน เช่น ขนาดภาพ การปรับแต่งภาพ ชั้นที่เพิ่มเข้าไป และจำนวนรอบการฝึก ทำให้ผลลัพธ์ที่แตกต่างกันไม่ได้ขึ้นอยู่กับตัวโมเดลเพียงอย่างเดียว
- มีเพียง InceptionV3 ที่ทดสอบกับชุดข้อมูล Test set ส่วน MobileNetV2 และ EfficientNetB3 แสดงผลเฉพาะค่า Validation set
- ระหว่างการฝึกใช้ Validation set เพื่อเลือกโมเดลที่ให้ผลดีที่สุด ทำให้ผลบน Validation อาจดูดีกว่าความสามารถในการใช้งานจริงเล็กน้อย
- ทุกโมเดลฝึกเฉพาะชั้นที่เพิ่มเข้ามาใหม่ยังไม่ได้ปรับชั้นเดิมที่เรียนรู้มาจาก ImageNet ให้เหมาะกับภาพสุนัขโดยเฉพาะ ซึ่งหากปรับเพิ่มเติมอาจช่วยให้โมเดลแม่นยำขึ้นได้
- การทดลองใช้ภาพจากชุดข้อมูลมาตรฐานเพียงชุดเดียว ยังไม่ได้ทดสอบกับภาพสุนัขจากแหล่งอื่นหรือภาพถ่ายในสถานการณ์จริง
